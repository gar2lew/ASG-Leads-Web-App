Date prepared: 2026-07-06

## Summary

These issues are known at release-candidate time. They do not block human review or staff UAT planning, but several block production deployment until fixed, rehearsed, or formally risk-accepted by the release owner.

## No-Go Triggers

Production release must stop if any of the following occur:

- Staff UAT fails without approved workaround.
- Any required validation fails on the final candidate.
- Firebase target is not explicitly confirmed.
- Release branch or tag target is ambiguous.
- Backup or rollback owner is missing.
- Live Salestrail sync, phone backfill write, migration, or Firebase deploy is requested without explicit approval.
- Secrets are printed, exposed, or committed.
